# OfficePlan Windows releases

This repository is the public binary release channel for the private OfficePlan source repositories.

- Windows packages are built from an explicitly selected, immutable annotated
  frontend source tag. The workflow verifies that the checked-out commit is
  exactly the commit referenced by that tag.
- The source checkout key is read-only and stored as a GitHub Actions secret.
- Tauri update manifests and signatures are generated by the release workflow.
- Release-candidate tags are published as GitHub prereleases; stable SemVer tags
  are published as normal releases.
- `channels/beta/latest.json` tracks the newest release candidate and
  `channels/stable/latest.json` tracks the newest stable release. This avoids
  GitHub's `releases/latest` behavior, which intentionally excludes
  prereleases, while keeping beta and stable clients on separate channels.
- Every published asset is covered by the generated SHA-256 checksum list and
  a GitHub build-provenance attestation.
- `latest.json` is consumed by installed OfficePlan desktop clients.

The current channel is an internal beta. Backup/restore acceptance and transactional email delivery remain separate production gates.
