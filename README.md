# OfficePlan Windows releases

This repository is the public binary release channel for the private OfficePlan source repositories.

- Windows packages are built from an explicitly selected, signed frontend source tag.
- The source checkout key is read-only and stored as a GitHub Actions secret.
- Tauri update manifests and signatures are generated by the release workflow.
- `latest.json` is consumed by installed OfficePlan desktop clients.

The current channel is an internal beta. Backup/restore acceptance and transactional email delivery remain separate production gates.
